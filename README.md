# Pocket Windows

Windows 11 в одной папке. Распаковал, открыл `Launcher.exe`, нажал «Запустить»: внутри готовый
рабочий стол с Claude Desktop и Firefox. Ничего не нужно устанавливать, ни Windows, ни Linux.

**[Скачать готовый комплект (Google Диск)](https://drive.google.com/drive/folders/17qU5W2SGMoi9TdhfqjYyj7fuWWYbNbtr)**
&nbsp;·&nbsp; один ZIP `Pocket-Windows-<версия>.zip` и файл `.sha256` для проверки.

## Что внутри

- **Портативно.** Никакого Setup: вся система лежит в папке, переносится и удаляется целиком.
- **Защищённый выход в сеть.** Windows ходит в интернет только через скрытый шлюз на Debian и твоё
  подключение (Hysteria2, SOCKS5, HTTP/HTTPS). Если подключение упало, прямой выход не открывается.
- **Как свой компьютер.** Общий буфер обмена с Windows, папки и диски ПК внутри Windows, полный экран
  (`Ctrl+Alt+F`) с переходом мыши на другие мониторы, значок в трее.
- **Простая панель.** Подключение, характеристики (память, процессоры, разрешение), проверка и
  восстановление компонентов в одном окне без прокрутки.
- **Готовая система.** Компактный Windows с Claude Desktop, Firefox и подготовленной учётной записью.

## Быстрый старт

1. Распакуй `Pocket-Windows-<версия>.zip` Проводником в новую папку, доступную для записи.
2. Открой `Launcher.exe` из этой папки. Нужны Windows 11 x64 с аппаратной виртуализацией,
   Windows Hypervisor Platform и .NET Framework 4.8.
3. В «Проверке» посмотри, всё ли готово. Если нужно включить платформу гипервизора, нажми
   «Подготовить этот ПК» и подтверди UAC.
4. В «Подключении» вставь ссылку на свой Proxy (`hysteria2://`, `socks5://`, `http(s)://`) или
   импортируй профиль. Нет своего: в этом же разделе можно купить готовый.
5. На главной нажми «Запустить». Сначала поднимается шлюз, затем открывается рабочий стол Windows.

Выключай Windows кнопкой в панели или меню в трее: закрытие панели Windows не останавливает,
она сворачивается в трей и показывает фактическое состояние при повторном открытии.

## Как это устроено

```
Launcher.exe (WPF)  ->  Python-контроллер  ->  QEMU/WHPX
                                                |-- Debian-шлюз (сеть, выбранное подключение)
                                                `-- Windows 11 (рабочий стол)
```

Панель на .NET Framework 4.8 управляет встроенным Python, тот запускает QEMU с ускорением WHPX.
Windows изолирована: сеть только через шлюз, доступ к папкам ПК по отдельному изолированному
адаптеру, обмен буфером и разрешением через небольшого помощника внутри гостя.
Подробности: [архитектура](docs/architecture.md).

## Подключение и безопасность

Поддерживаются Hysteria2 (TCP/UDP), SOCKS5 и HTTP/HTTPS CONNECT. Сервер должен быть уже настроен:
панель не устанавливает VPN на пустой VPS. Пароли в `profiles/profiles.json` защищены DPAPI
текущего пользователя Windows, при переносе на другой ПК их нужно ввести заново. ZIP не шифруется.
Успешная проверка профиля не означает, что он уже применён к работающей Windows: изменения
вступают в силу при следующем запуске.

## Восстановление

- **Восстановить Python и QEMU** возвращает компоненты из локального проверенного архива.
- **Восстановить шлюз** заменяет только шлюз; диск Windows и подключения не трогаются.
- **Восстановить сеанс** появляется после сбоя и сохраняет предыдущий журнал.
- Повреждённый диск Windows автоматически не исправляется: нужна отдельная исправная копия.

## Исходники и сборка

В Git лежат исходники панели, служебные сценарии, тесты и документация. Образы, Python/QEMU,
пользовательские профили и готовые EXE в Git не входят, поэтому чистый clone это не готовая
portable-папка.

```powershell
& '.\scripts\Build-Launcher.ps1' -OutputDirectory 'C:\Build\launcher-new'
```

Используй новое имя выходного каталога: сценарий не заменяет существующий EXE.
Порядок единой сборки, проверок и выпуска: [packaging.md](docs/packaging.md).
Сборка движка QEMU с исправлением окна SDL: [qemu-build.md](docs/qemu-build.md).
