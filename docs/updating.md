# Как обновить Pocket Windows

Обновление приложения не заменяет диск Windows, установленные внутри неё программы, сохранённые подключения и личные настройки. Полный комплект для первой установки и пакет обновления — разные архивы.

Номер установленной версии смотри в разделе **«Обновления»** лаунчера; в старой копии его можно найти в файле `release-info.json` рядом с `Launcher.exe` (поле `release_id`). Свежий опубликованный выпуск находится на странице [Latest](https://github.com/TheFactChain/pocket-windows/releases/latest).

## Перед обновлением

1. Сохрани работу и штатно выключи гостевую Windows. Дождись её остановки.
2. Для резервной копии скопируй всю остановленную папку Pocket Windows на другой диск. Она включает личные данные; храни её соответственно.
3. Оставь папку доступной для записи и проверь свободное место. Лаунчер дополнительно проверит место для загрузки, установки и отката.
4. Выбери ниже инструкцию **для своей исходной версии**. Не распаковывай `app` поверх установки вручную и не заменяй диск Windows другим образом.

## Версия 2026.10.25.3 и новее

Полный комплект **2026.10.25.7** на Google Диске уже включает обновлятор. Для него, в том числе сразу после первой распаковки, используется этот обычный путь.

1. Открой **«Обновления»** в лаунчере.
2. Нажми **«Проверить»**, затем **«Обновить»** и дождись завершения. Во время установки панель может закрыться и открыться снова.
3. Проверь новый номер версии и затем запусти гостевую Windows. Гостевой помощник обновится при следующем входе в неё.

Новый обновлятор проверяет содержимое файлов и скачивает изменившиеся части с продолжением загрузки. Размер зависит от исходной версии и кэша. Если предложена отдельная полная загрузка, прочитай её размер перед подтверждением. Не нужно вручную скачивать `-chunks.zip`, `-update*.json` или `-updater.zip`.

Эта инструкция относится к обычному обновлению исправной копии. Перенесённая или прерванная старая операция может требовать отдельного восстановления; не запускай поверх неё ручную замену файлов.

## Версия 2026.10.24.13

Для неё проверен переход на **2026.10.25.7 внешним средством обновления**. Старую встроенную кнопку обновления для этого перехода не используй: она не заменяет активный шлюз полностью. После перехода открой новый лаунчер и выполни обычное обновление до актуального выпуска.

1. Штатно выключи гостевую Windows и закрой все панели этой копии.
2. Скачай `Pocket-Windows-2026.10.25.7-app.zip` из [выпуска 2026.10.25.7](https://github.com/TheFactChain/pocket-windows/releases/tag/v2026.10.25.7).
3. Открой PowerShell. Замени пути **в первых двух строках** на папку своей установленной копии (ту, где `Launcher.exe`) и скачанный ZIP. Остальной блок выполни без изменений:

```powershell
$installed = 'D:\Pocket Windows'
$archive = 'C:\Users\YOUR_NAME\Downloads\Pocket-Windows-2026.10.25.7-app.zip'
$ErrorActionPreference = 'Stop'
$expected = '70379972667e923383c35519c73812072b009cb2448bf9710e8ef89e13798c72'
if ((Get-FileHash -LiteralPath $archive -Algorithm SHA256).Hash -ne $expected) {
    throw 'SHA256 mismatch. The archive will not be used.'
}
$stage = Join-Path (Split-Path -Parent $archive) ('PocketWindows-update-' + [Guid]::NewGuid().ToString('N'))
Expand-Archive -LiteralPath $archive -DestinationPath $stage
& "$stage\app\runtime\python-3.12.14\python.exe" -X utf8 -I -B "$stage\app\scripts\release_portable.py" update --release $stage --target $installed
if ($LASTEXITCODE -ne 0) { throw 'Update did not finish. Keep the error and recovery files.' }
```

После успешного завершения открой `Launcher.exe` **в установленной папке**, затем раздел «Обновления». Эта инструкция воспроизводит опубликованный переход 24.13 → 25.7: на отдельной копии были сверены 990 файлов приложения и сохранение диска, UEFI и настроек. Это не подтверждение перехода с 24.12 или живой приёмки всех последующих функций.

## Если обновление не завершилось

- Не запускай несколько установок одновременно. Сохрани текст ошибки и исходную версию.
- Если лаунчер открывается, вернись в «Обновления» и следуй сообщению о продолжении или восстановлении. Уже проверенные части могут использоваться повторно.
- Не удаляй `state`, кэш, журнал или сохранённый комплект обновлятора: они могут требоваться для продолжения и отката.
- Если лаунчер не открывается или сообщает об ошибке восстановления, создай [обращение](https://github.com/TheFactChain/pocket-windows/issues/new) с исходной и целевой версиями. Перед публикацией убери секреты и личные пути из снимков и журналов.

Откат приложения не восстанавливает повреждённый диск Windows. Для пользовательских данных нужна отдельная резервная копия.
