# Исходники Pocket Windows

Полные правила проекта лежат двумя уровнями выше: `..\..\AGENTS.md` (карта папок, что программа, что мусор,
порядок выпуска). Прочитай их до работы. Этот файл повторяет только то, что относится к самому репозиторию.

- Ветка `files-access`, коммиты локальные. `git push` и публикация только по просьбе владельца.
- В Git лежат только исходники, тесты и документация. Диски, ZIP, EXE, DLL, логи и картинки проверок не коммитятся.
  `scripts\check_workspace.py` и `tests\test_repo_hygiene.py` проверяют это.
  Исключение: отобранные изображения README в `docs/assets/readme/`, перечисленные в `README_IMAGES`
  проверки порядка. Это материалы документации; случайные снимки проверок по-прежнему запрещены.
- Выпуск собирается только из чистого коммита: `git status --short` перед `prepare` должен быть пустым.
- Временные файлы проверок складывай в `..\Служебное\_temp\<дата>-<задача>\`, а не в корень репозитория и не в `launcher-wpf\`.
- Папки `runtime\`, `state\`, `logs\` вне Git. `runtime\` нужна для сборки, `state\` и `logs\` чистятся после работы.
- Задачи только в Beads: `bd` из этой папки находит корневую базу через `.beads\redirect`.
